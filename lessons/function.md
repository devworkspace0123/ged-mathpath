# Functions

## Learning Goals

By the end of this lesson, you should be able to:

* Understand what a function is.
* Identify the input and output of a function.
* Use function notation.
* Evaluate functions.
* Determine whether a relation is a function.
* Use tables, graphs, equations, and mapping diagrams.
* Find the domain and range.
* Understand linear and nonlinear functions.
* Interpret functions in real-world situations.
* Compare functions represented in different ways.

---

# 1. What Is a Function?

A **function** is a relationship between inputs and outputs.

Each input can have **one output**.

We can think of a function as a machine:

$$
\text{Input}\longrightarrow\boxed{\text{Function}}\longrightarrow\text{Output}
$$

For example:

$$
2\longrightarrow\boxed{+3}\longrightarrow5
$$

The input is:

$$
2
$$

The output is:

$$
5
$$

---

# 2. The Function Rule

Consider the rule:

$$
y=2x+3
$$

This rule tells us how to find the output from the input.

If:

$$
x=4
$$

then:

$$
y=2(4)+3
$$

$$
y=8+3
$$

$$
\boxed{y=11}
$$

So:

$$
4\longrightarrow11
$$

---

# 3. Function Notation

Instead of writing:

$$
y=2x+3
$$

we can write:

$$
\boxed{f(x)=2x+3}
$$

This is read as:

> $f$ of $x$.

The notation:

$$
f(x)
$$

means the output of the function when the input is $x$.

It does **not** mean:

$$
f\times x
$$

---

# 4. Evaluating a Function

Suppose:

$$
f(x)=3x+2
$$

Find:

$$
f(5)
$$

Replace every $x$ with 5:

$$
f(5)=3(5)+2
$$

$$
f(5)=15+2
$$

Therefore:

$$
\boxed{f(5)=17}
$$

---

# 5. Another Example

Given:

$$
f(x)=x^2-4
$$

Find:

$$
f(3)
$$

Substitute:

$$
f(3)=3^2-4
$$

$$
f(3)=9-4
$$

$$
\boxed{f(3)=5}
$$

---

# 6. Evaluating Functions with Negative Inputs

Given:

$$
f(x)=x^2+2x
$$

Find:

$$
f(-3)
$$

Substitute:

$$
f(-3)=(-3)^2+2(-3)
$$

$$
=9-6
$$

$$
\boxed{f(-3)=3}
$$

Always use parentheses when substituting negative numbers.

---

# 7. What Makes a Relation a Function?

A relation is a function if:

> Each input has exactly one output.

For example:

$$
1\to5
$$

$$
2\to7
$$

$$
3\to9
$$

This is a function because each input has only one output.

---

# 8. A Relation That Is Not a Function

Consider:

$$
2\to5
$$

and:

$$
2\to8
$$

The input 2 has two different outputs.

Therefore, this is:

$$
\boxed{\text{Not a function}}
$$

---

# 9. The Vertical Line Test

A graph represents a function if every vertical line crosses the graph at most once.

This is called the:

$$
\boxed{\text{Vertical Line Test}}
$$

If a vertical line crosses the graph more than once, the graph is not a function.

---

# 10. Function Tables

A function can be represented by a table.

Consider:

$$
f(x)=2x+1
$$

| $x$ | $f(x)$ |
| --- | ------ |
| 0   | 1      |
| 1   | 3      |
| 2   | 5      |
| 3   | 7      |

Each input has exactly one output.

Therefore, this table represents a function.

---

# 11. Mapping Diagrams

A function can also be represented with arrows.

Example:

$$
1\longrightarrow4
$$

$$
2\longrightarrow6
$$

$$
3\longrightarrow8
$$

Each input has one arrow leaving it.

Therefore, it is a function.

---

# 12. Multiple Inputs Can Have the Same Output

This is allowed.

For example:

$$
1\to4
$$

$$
2\to4
$$

$$
3\to4
$$

This is still a function because each input has only one output.

The rule is:

> One input cannot have multiple outputs.

But:

> Multiple inputs may have the same output.

---

# 13. Domain

The **domain** is the set of all possible input values.

Usually, the domain contains the $x$-values.

For example:

$$
\{1,2,3,4\}
$$

could be the domain.

---

# 14. Range

The **range** is the set of all possible output values.

Usually, the range contains the $y$-values.

For example:

$$
\{5,7,9,11\}
$$

could be the range.

---

# 15. Example: Domain and Range

Consider:

| $x$ | $y$ |
| --- | --- |
| 1   | 4   |
| 2   | 6   |
| 3   | 8   |

The domain is:

$$
\boxed{\{1,2,3\}}
$$

The range is:

$$
\boxed{\{4,6,8\}}
$$

---

# 16. Domain Restrictions

Some functions have restrictions.

Consider:

$$
f(x)=\frac{1}{x-3}
$$

The denominator cannot equal zero.

Therefore:

$$
x-3\ne0
$$

$$
\boxed{x\ne3}
$$

So the domain is all real numbers except 3.

---

# 17. Square Root Domain Restrictions

Consider:

$$
f(x)=\sqrt{x-2}
$$

The expression inside a square root cannot be negative.

Therefore:

$$
x-2\ge0
$$

$$
\boxed{x\ge2}
$$

The domain is:

$$
[2,\infty)
$$

---

# 18. Linear Functions

A linear function has the form:

$$
\boxed{f(x)=mx+b}
$$

where:

* $m$ = slope
* $b$ = $y$-intercept

Example:

$$
f(x)=3x+2
$$

The slope is:

$$
\boxed{3}
$$

The $y$-intercept is:

$$
\boxed{2}
$$

---

# 19. Finding the Slope

The slope formula is:

$$
\boxed{m=\frac{y_2-y_1}{x_2-x_1}}
$$

Given:

$$
(2,3)
$$

and:

$$
(5,9)
$$

the slope is:

$$
m=\frac{9-3}{5-2}
$$

$$
m=\frac{6}{3}
$$

$$
\boxed{m=2}
$$

---

# 20. Interpreting Slope

The slope represents the rate of change.

For example:

$$
f(x)=5x+10
$$

The slope is:

$$
5
$$

This means:

> The output increases by 5 for every 1-unit increase in the input.

---

# 21. Increasing and Decreasing Functions

If:

$$
m>0
$$

the function is increasing.

Example:

$$
f(x)=2x+1
$$

If:

$$
m<0
$$

the function is decreasing.

Example:

$$
f(x)=-3x+5
$$

---

# 22. Constant Functions

A constant function always has the same output.

Example:

$$
f(x)=7
$$

No matter what $x$ is:

$$
f(x)=7
$$

Its graph is a horizontal line.

---

# 23. Nonlinear Functions

A nonlinear function does not form a straight line.

Examples include:

### Quadratic

$$
f(x)=x^2
$$

### Exponential

$$
f(x)=2^x
$$

### Absolute Value

$$
f(x)=|x|
$$

---

# 24. Quadratic Functions

A quadratic function has the form:

$$
\boxed{f(x)=ax^2+bx+c}
$$

Example:

$$
f(x)=x^2-4x+3
$$

Its graph is a parabola.

---

# 25. Exponential Functions

An exponential function has the variable in the exponent.

Example:

$$
f(x)=2^x
$$

The output changes by a constant factor rather than a constant difference.

---

# 26. Comparing Linear and Nonlinear Functions

Consider the table:

| $x$ | $f(x)$ |
| --- | ------ |
| 1   | 3      |
| 2   | 6      |
| 3   | 9      |
| 4   | 12     |

The differences are:

$$
+3,\quad+3,\quad+3
$$

Because the difference is constant, the function is linear.

---

## Nonlinear Example

| $x$ | $f(x)$ |
| --- | ------ |
| 1   | 1      |
| 2   | 4      |
| 3   | 9      |
| 4   | 16     |

The differences are not constant.

This is a quadratic function:

$$
f(x)=x^2
$$

---

# 27. Finding an Equation from a Table

Consider:

| $x$ | $f(x)$ |
| --- | ------ |
| 0   | 4      |
| 1   | 7      |
| 2   | 10     |

The output increases by 3 each time.

Therefore:

$$
m=3
$$

When:

$$
x=0
$$

the output is:

$$
4
$$

Therefore:

$$
\boxed{f(x)=3x+4}
$$

---

# 28. Finding an Equation from Two Points

Suppose a line passes through:

$$
(2,5)
$$

and:

$$
(4,11)
$$

### Step 1: Find the slope

$$
m=\frac{11-5}{4-2}
$$

$$
m=\frac{6}{2}=3
$$

So:

$$
y=3x+b
$$

### Step 2: Use one point

Use:

$$
(2,5)
$$

$$
5=3(2)+b
$$

$$
5=6+b
$$

$$
b=-1
$$

Therefore:

$$
\boxed{f(x)=3x-1}
$$

---

# 29. Function Transformations

Starting with:

$$
f(x)=x^2
$$

Adding a number outside the function:

$$
f(x)+3=x^2+3
$$

moves the graph upward by 3.

Subtracting 3:

$$
f(x)-3=x^2-3
$$

moves it downward by 3.

---

# 30. Function Notation and Operations

Suppose:

$$
f(x)=2x+3
$$

and:

$$
g(x)=x-1
$$

Then:

$$
(f+g)(x)=f(x)+g(x)
$$

Substitute:

$$
(f+g)(x)=(2x+3)+(x-1)
$$

Combine:

$$
\boxed{(f+g)(x)=3x+2}
$$

---

# 31. Composition of Functions

Function composition means putting one function inside another.

It is written:

$$
\boxed{f(g(x))}
$$

Suppose:

$$
f(x)=2x+1
$$

and:

$$
g(x)=x+3
$$

Then:

$$
f(g(x))=2(x+3)+1
$$

Simplify:

$$
\boxed{f(g(x))=2x+7}
$$

---

# 32. Inverse Functions

An inverse function reverses the input and output.

If:

$$
f(x)=x+3
$$

then the inverse function is:

$$
f^{-1}(x)=x-3
$$

The original function adds 3.

The inverse subtracts 3.

---

# 33. Real-World Functions

Functions are used to model real-world relationships.

Examples:

* Time and distance
* Hours worked and wages
* Temperature and energy use
* Number of products and total cost
* Time and population

---

# 34. Example: Cost Function

A taxi charges a $5 starting fee and $2 per mile.

Let:

$$
m=\text{number of miles}
$$

The cost function is:

$$
\boxed{C(m)=2m+5}
$$

For 10 miles:

$$
C(10)=2(10)+5
$$

$$
C(10)=25
$$

The total cost is:

$$
\boxed{\$25}
$$

---

# 35. Interpreting Function Notation

Suppose:

$$
C(m)=2m+5
$$

Then:

$$
C(10)=25
$$

means:

> The cost of traveling 10 miles is $25.

The input represents:

$$
\boxed{\text{miles}}
$$

The output represents:

$$
\boxed{\text{cost}}
$$

---

# 36. Comparing Functions

A function may be represented by:

* An equation
* A table
* A graph
* A verbal description

The GED may ask you to compare two functions represented in different ways.

---

## Example

Function A:

$$
f(x)=3x+2
$$

Function B:

| $x$ | $g(x)$ |
| --- | ------ |
| 0   | 5      |
| 1   | 8      |
| 2   | 11     |

Function B increases by 3 each time.

Therefore, both functions have the same rate of change:

$$
\boxed{3}
$$

---

# 37. Common Mistakes

## Mistake 1: Thinking $f(x)$ Means Multiplication

Incorrect:

$$
f(x)=f\times x
$$

Correct:

$$
\boxed{f(x)\text{ represents the output of the function}}
$$

---

## Mistake 2: Substituting Incorrectly

Given:

$$
f(x)=x^2+3
$$

To find:

$$
f(-2)
$$

correctly write:

$$
f(-2)=(-2)^2+3
$$

not:

$$
-2^2+3
$$

Parentheses are important.

---

## Mistake 3: Confusing Domain and Range

### Domain

Inputs.

Usually:

$$
x
$$

### Range

Outputs.

Usually:

$$
y
$$

---

## Mistake 4: Thinking Every Relation Is a Function

A function cannot have one input connected to two different outputs.

---

# 38. A Reliable Strategy

When working with functions:

1. Identify the input.
2. Identify the output.
3. Substitute values carefully.
4. Check whether each input has only one output.
5. Determine the domain and range.
6. Identify the type of function.
7. Interpret the function in context.

# Summary

A function is a relationship between inputs and outputs.

The main notation is:

$$
\boxed{f(x)}
$$

To evaluate a function:

1. Substitute the input.
2. Simplify.
3. Find the output.

Important concepts:

### Domain

The set of possible inputs.

### Range

The set of possible outputs.

### Function Rule

The equation that connects input and output.

### Linear Function

$$
\boxed{f(x)=mx+b}
$$

### Quadratic Function

$$
\boxed{f(x)=ax^2+bx+c}
$$

The key idea is:

$$
\boxed{\text{Every input of a function has exactly one output.}}
$$
